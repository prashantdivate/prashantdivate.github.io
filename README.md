# PD//DEV — Futuristic Hugo Portfolio + Blog

A custom Hugo site for an embedded Linux engineer. No paid hosting, backend, database or external CMS is required.

## Features

- Futuristic responsive landing page
- Animated system/orbit visualization
- Engineering blog and tag filters
- Project showcase cards
- Built-in client-side search
- Syntax-highlighted code blocks
- Responsive article layout + table of contents
- Scroll/reveal animations
- SEO-friendly static HTML
- RSS generated by Hugo
- Automatic GitHub Pages deployment with GitHub Actions

## 1. Run locally

Install Hugo Extended, then:

```bash
hugo server -D
```

Open the URL printed by Hugo, usually `http://localhost:1313/`.

## 2. Publish to GitHub Pages

### Recommended: profile website

Create a repository named exactly:

```text
prashantdivate.github.io
```

Copy all files from this project into the repository, then:

```bash
git add .
git commit -m "Initial personal website"
git push origin main
```

On GitHub go to:

`Repository -> Settings -> Pages -> Build and deployment -> Source`

Choose **GitHub Actions**.

The included `.github/workflows/hugo.yml` will build and deploy the website.

### Also works in a normal project repository

The workflow obtains the correct GitHub Pages base URL automatically, so a repository such as `my-blog` can deploy at `https://USERNAME.github.io/my-blog/`.

## 3. Write a blog post

Create a Markdown file under `content/posts/`:

```markdown
---
title: "My New Post"
date: 2026-09-12T10:00:00+05:30
description: "One-line summary for cards and search."
tags: ["Yocto", "Linux"]
categories: ["Embedded Linux"]
reading: "6 min"
---

Write the article here using Markdown.
```

Then commit and push. GitHub Actions redeploys automatically.

## 4. Add a project

Create `content/projects/project-name.md` and use one of the existing project files as a template.

## 5. Personalize

Edit `hugo.toml`:

- `title`
- `params.author`
- `params.role`
- `params.location`
- `params.github`
- `params.linkedin`
- `params.email`

The current LinkedIn/email values are intentionally left as `#` because they were not provided.

## Notes

The site uses Google Fonts (`Inter` and `JetBrains Mono`). If you want a completely network-independent site, replace these with local/system fonts and remove the font links from `layouts/_default/baseof.html`.
