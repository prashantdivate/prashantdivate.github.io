# Design and implementation references

The requested reference was Torizon's engineering blog:
https://torizon.github.io/blog/
https://github.com/torizon/blog

This package follows the same general architecture: Markdown content, Hugo
layouts/assets, a GitHub Actions build, and GitHub Pages serving generated files.
Its templates, styling, JavaScript, illustrations, and sample article text are
an original implementation. Torizon's source theme, posts, logos, photographs,
and company identity are not bundled or presented as the user's work.

Public project cards refer to:
- https://github.com/prashantdivate/yocto-lens
- https://github.com/prashantdivate/VulnTrack

The cards' terminal/dashboard illustrations are explicitly concept previews,
not product screenshots, measured performance, or live device telemetry.

Starter notes are editorial examples. Each is visibly labeled and includes
appropriate source links. Review them before publishing as your own writing.
The supplied About/profile copy is editable, with no invented contact details.

The layout uses system fonts. No third-party font files are distributed.
Hugo, GitHub Actions, and Playwright are external build/test tools, not vendored
into this ZIP. Their licenses and service terms remain their own.
